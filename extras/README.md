# extras

Standalone odds and ends. Nothing here is imported by the bot, and nothing here
runs in CI or on the host.

- `screen_graffiti.py` — windows-only toy that draws "you are birdvirus" at random
  points on the desktop until you ctrl-c it. it lived in `birdvirus-cloud/` as
  `I love you.py`, which is neither a node file nor a filename without a space in it.
